# Order Processing & Inventory Automation

An n8n automation concept for processing incoming orders and updating inventory records.

## Setup
1. Import the workflow JSON once added to this repository.
2. Reconnect form, spreadsheet/database, and notification credentials.
3. Configure your own product identifiers and stock rules.
4. Test duplicate orders, unavailable stock, and failed updates.

## Security
Remove private spreadsheet IDs and customer information before sharing. End-to-end testing is not confirmed.

## Project status
This README documents the project scope and setup expectations. The workflow export must be present in the repository before it can be imported; validate the finished workflow in your own n8n instance before relying on it.
